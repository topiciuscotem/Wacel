🔌 كيف تربط قاعدة SQL بالموقع - 3 دقايق

هاد الشرح باش تخلي wacel-database.sql يخدم مع Vercel بلا سيرفر

الخطوة 1: إنشاء Supabase (مجاني 100%)

  1. سير لـ supabase.com > Start free
  2. New Project > Name: wacel-ma > Password: دير شي باسورد
  3. استنى 2 دقايق حتى يوجد
  4. SQL Editor > New Query > انسخ محتوى wacel-database.sql كامل ودير Run
  5. غادي تشوف 20 جدول تخلقو ✅

الخطوة 2: جيب المفاتيح

Project Settings > API > انسخ:

NEXT_PUBLIC_SUPABASE_URL = https://xxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY = eyJhbGc...

الخطوة 3: ركبهم فـ Vercel

  1. Vercel Dashboard > مشروع wacel > Settings > Environment Variables
  2. زيد: supabaseUrl و supabaseKey
  3. أو أسهل: حل wacel-api.js وبدل السطرين الأولين بمعلوماتك
const WACEL_CONFIG = {
  supabaseUrl: 'https://YOUR_ID.supabase.co',
  supabaseKey: 'YOUR_ANON_KEY',
  whatsappNumber: '2126XXXXXXXX' // نمرتك
};
