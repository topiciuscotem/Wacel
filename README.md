# Wacel - المكتبة الإلكترونية 📚
Wacel is a free open digital library for Arabic readers.

🔗 Live Demo: https://wacel.vercel.app

## ✨ المميزات
- مكتبة كتب عربية وعالمية مجانية
- واجهة سريعة وتفاعلية
- يعمل على الهاتف والكمبيوتر

## 🚀 التقنيات
HTML5, CSS3, JavaScript, PWA
